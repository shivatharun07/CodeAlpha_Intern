# Task 4: Network Intrusion Detection System (NIDS)

## Objective
To monitor network traffic and detect suspicious activity using a network intrusion detection system.

## Tool Used
Snort (Open-source NIDS)

## Implementation
A custom Snort rule was created to detect HTTP traffic. Alerts were generated when matching packets were detected.

## Outcome
The system successfully detected network activity and generated alerts, demonstrating effective intrusion detection.
